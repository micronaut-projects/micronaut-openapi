To use micronaut openapi views (Swagger UI, OpenAPI Explorer, Scalar, ReDoc, RapiDoc) you need to add static resources to Spring configuration like this:

.Example Swagger UI resources routing config
[source,yaml]
----
spring:
  web:
    resources:
      static-locations: classpath:/META-INF/swagger,classpath:/META-INF/swagger/views/swagger-ui/
----
