To support incremental annotation processing, you need to explicitly set the path to
the project directory through the annotation processor setting `micronaut.openapi.project.dir` like this:

.Gradle with KAPT
[source,groovy]
----
kapt {
    arguments {
        arg("micronaut.openapi.project.dir", projectDir.toString())
    }
}
----

.Gradle with KSP
[source,groovy]
----
ksp {
    arg("micronaut.openapi.project.dir", projectDir.toString())
}
----
====

[NOTE]
====
If you use KSP we recommend to set **micronaut.openapi.project.dir**, otherwise dummy file will be created.
That is limitation of KSP, for automatically detect project directory need to create this file, but KSP doesn't delete dummy file automatically:
