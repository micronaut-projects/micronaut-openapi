It is possible to tweak the OpenAPI processing via standard way with micronaut environments (application.yml file).

.application.yml Example
[source,yaml]
----
micronaut:
  openapi:
    target:
     file: myspecfile.yml
    property:
      naming:
        strategy: KEBAB_CASE
----

Also, you can use properties from `application.yml` file for placeholders.

.application.yml Sample properties for placeholders
[source,yaml]
----
my:
  api:
    title: Hello World
----

The following application class resolves its title from the `my.api.title` property (the other placeholders come from `openapi.properties`, see <<propertiesFileConfiguration>>):
